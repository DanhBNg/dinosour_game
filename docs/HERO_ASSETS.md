# Species hero artwork

Six static portraits in `assets/heroes/` were generated with the built-in image generation tool on 2026-09-28, using screenshots rendered from the actual demo models as reference. They are interpretive game illustrations, not exact 3D renders or scientific reconstructions. The models used in learning remain unchanged.

Common prompt: cinematic realistic premium dinosaur game species hero artwork, landscape 1536x1024; preserve actual model silhouette, proportions, skin colors/markings, head and horn/plate/fin shapes; remove screenshot UI; one creature filling left 65–70%, quiet environment at right for HTML profile; natural textures, warm rim lighting, no text/logo/border/other creatures.

| Asset | Environment and specific constraints |
| --- | --- |
| trex.png | Fern-lined rocky river, distant waterfall; brown skin, cream underside, original head shape |
| stego.png | Sunlit fern forest; green-brown skin, red/cream plates and tail spikes |
| trice.png | Misty meadow at golden hour; original horns, patterned frill and large scales |
| ptero.png | Flying over coastal cliffs; original beak, crest and brown wing membrane |
| mosa.png | Underwater turquoise lagoon; original dark body, gold back markings and fins |
| deino.png | Mossy forest beside stream; olive skin, striped tail, slender build, long forearms; no added feathers to preserve this game model's design |

Generated originals retained under the tool's generated_images directory; copies are stored in this project. Original reference screenshots were captured in `3d-model/artifacts/game-redesign/`. Prompts prioritize resemblance to supplied assets; use the species information panel for distinctions between artistic reconstruction and fossil evidence.
