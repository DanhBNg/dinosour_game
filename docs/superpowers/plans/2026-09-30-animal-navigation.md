# Animal navigation overhaul

Approved design: home → world map → habitat and six knowledge topics → interactive 3D actions.

- Home: enlarge transparent model sprites, shuffle visible species in the two open worlds without consecutive repeats. Four supplied models represent locked worlds. Short landscape phones can scroll the home painting vertically.
- Maps: animated model pins replace generated portrait pins; remove bottom catalogue. Keep pins in painting coordinates.
- Knowledge: habitat on entry, six topics then 3D, no species switching. Swipe or explicit topic arrows navigate, last step opens actions. No WebGL or model fetch on knowledge pages.
- Loading: animate the selected model over its environment until interactive model renders. Abort stale UI updates after back/navigation; retry remains accessible on failure.
- Validate: desktop and short landscape, map pins, first habitat, six topic order, action transition/reload/back, delayed model loading and errors, all existing model actions. Render four locked representatives offline from supplied assets; no Blender.

## Icon framing correction
Each animation uses alpha bounds across all 48 frames. Horizontal silhouette is centered; walking animals use a lower baseline inside the ring, aquatic/flying silhouettes use the center. Bounds are regenerated by scripts/measure-preview-bounds.mjs. Avoid a universal CSS zoom.

Locked representatives are offline renders of user-supplied elephant (idle), gorilla (idle), cow (Animation), wolf (02_walk). Wolf FBX 6100 was decoded with ufbx and baked to 48 vertex frames for rendering; no Blender used. Only WebP assets ship to clients.
